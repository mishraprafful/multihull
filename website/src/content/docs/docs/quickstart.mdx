Six commands take a container from your laptop to two GPU providers behind one URL.

:::note
0.1.0 deploys to Kubernetes and Modal. RunPod, Baseten and Replicate render plans only. See the [release notes](/docs/reference/release-notes/) for what is proven and what is not.
:::

<Steps>

1. **Install**

   ```sh
   uv tool install multihull==0.1.0
   hull --version
   ```

2. **Initialise a spec**

   `hull init` detects a Dockerfile and writes `multihull.yaml`.

   ```sh
   hull init
   ```

3. **Check credentials**

   ```sh
   $ hull doctor
   gke-prod    OK
   modal-main  OK
   ```

   Credentials come from each provider's native location (kubeconfig, `~/.modal.toml` or `MODAL_TOKEN_ID` and `MODAL_TOKEN_SECRET`). Nothing goes in the file.

4. **Prepare the cluster**

   The spec targets the `multihull` namespace. Installing the chart creates it and runs the router; `hull deploy` stops with a one-line error when it is missing.

   ```sh
   helm install multihull oci://ghcr.io/mishraprafful/charts/multihull --version 0.1.0 \
     -n multihull --create-namespace
   ```

5. **Plan**

   Renders every provider's native payload to `.multihull/plan/` and diffs it against recorded state.

   ```sh
   hull plan
   ```

6. **Deploy and watch**

   The spec from `hull init` protects the route with keys from `<NAME>_API_KEYS`, where `<NAME>` is the service name in capitals with `-` as `_`. `hull deploy` stops while that variable holds no keys.

   ```sh
   $ export LLAMA_8B_API_KEYS="hull_$(openssl rand -hex 4)_$(openssl rand -hex 32)"
   $ hull deploy
   $ hull status
   gke-prod    Ready  2/2  L4    https://gke.int/llama
   modal-main  Ready  1/1  A10G  https://acme--multihull-llama-8b.modal.run
   ```

   All targets apply concurrently. One failing target never blocks the others.

</Steps>

## Next

- Try the [demo](/docs/demo/): `make demo` runs three local docker targets behind one URL, streams completions through it and lets you stop the primary with zero client errors; `make demo-cloud` does the same on kind and Modal.
- Run the router: see [Router overview](/docs/router/overview/) or the Helm chart in `charts/multihull`.
- Prove failover: scale the primary to zero under load and watch `router_failovers_total`; `hull failover test` is planned, not built.
- Example spec: `examples/llama-8b/multihull.yaml` in the repository.
