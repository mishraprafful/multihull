## A minimal spec

<p class="mh-lead">Two targets, one hostname. The control plane turns this into a Kubernetes Deployment and a Modal app.</p>

</div>
<div class="mh-split-visual">

```yaml title="multihull.yaml"
apiVersion: multihull/v1
name: llama-8b

container:
  image: ghcr.io/acme/vllm-llama:1.4.0
  port: 8000
  health: {path: /health}

resources:
  gpu: [L4, A10G]

targets:
  - provider: gke-prod
    type: kubernetes
    priority: 1
  - provider: modal-main
    type: modal
    priority: 2

route:
  hostname: llama.api.acme.com
  protocol: openai
```
