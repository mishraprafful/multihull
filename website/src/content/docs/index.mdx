## A minimal spec

```yaml title="multihull.yaml"
apiVersion: multihull/v1
name: llama-8b

container:
  image: ghcr.io/acme/vllm-llama:1.4.0
  port: 8000
  health: {path: /health}

resources:
  gpu: [L4, A10G]

targets:
  - provider: gke-prod
    type: kubernetes
    priority: 1
  - provider: modal-main
    type: modal
    priority: 2

route:
  hostname: llama.api.acme.com
  protocol: openai
```
