Multihull docs site (Astro Starlight, "Open water" theme).

Run: `npm install && npm run dev` (http://localhost:4321). Build: `npm run build` (output in `dist/`).

`npm run build` first copies `../docs/design/architecture-plan.md` into `src/content/docs/docs/design/architecture.md`; edit the source doc, not the copy.
