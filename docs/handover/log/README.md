# Session files

One file per session, `YYYY-MM-DD-<topic>.md`, never edited by another session. The files are the archive; `docs/handover.md` is what gets read.

Write a file only when the session produced a lesson (a trap, a non-obvious cause, a decision and its reason) or changed current state. A few lines, facts with PR, issue or run ids. No diary of what the PR did; the PR description has that. Copy the lesson as one line into "Lessons" in `docs/handover.md`, and a decision into its table.
