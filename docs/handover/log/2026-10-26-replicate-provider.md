# 2026-10-26 Replicate translator (issue 65)

- Branch `feat/replicate-provider`, PR 175. No Replicate credential was available: everything is tested against `python/tests/fake_replicate.py` (an `httpx.MockTransport` that enforces the documented field sets, instance limits and the 15-minute delete rule) and a fake Cog CLI, never against Replicate.
- Routing: the architecture plan already limits Replicate to Cog images, so a service with a Replicate target is a Cog model everywhere. Replicate's deployment predictions endpoint and a Cog server take the same `POST .../predictions` body, so the endpoint is the deployment URL and the router forwards unchanged, adding `Authorization: Bearer` and `Prefer: wait=60`. No shim, no protocol translator.
- Facts used, all from `https://api.replicate.com/openapi.json` unless noted: `POST /v1/deployments` needs `name`, `model`, `version`, `hardware`, `min_instances` (0 to 5), `max_instances` (0 to 20) and returns 200; `PATCH` takes any of `version`, `hardware`, `min_instances`, `max_instances` and creates a new release; `DELETE` only after 15 minutes offline and unused, 204; `GET /v1/deployments` pages with an absolute `next` URL; the deployment object has `owner`, `name`, `current_release{number, model, version, created_at, configuration{hardware, min_instances, max_instances}}` and nothing about instances; `POST /v1/models` needs `owner` (the token's account), `name`, `visibility`, `hardware`, answers 201; `GET /v1/models/{owner}/{name}` has `latest_version.id`; `GET /v1/account` gives `username`; `GET /v1/hardware` lists `{name, sku}`; predictions answer 201 (final with `Prefer: wait`) or 202, and `Prefer` matches `^wait(=n)?$` up to 60 s.
- Cog: `cog push r8.im/<owner>/<model>` needs the model to exist (https://replicate.com/docs/guides/build/push-a-model); `cog login --token-stdin` with the CLI auth token is what `replicate/setup-cog` runs (`action.yml`); the Cog server serves `GET /health-check` and `POST /predictions`, sync unless `Prefer: respond-async` (https://github.com/replicate/cog/blob/main/docs/http.md).
- Unknowns for the first live run: the status of a refused `DELETE`, whether an unchanged `cog push` makes a new version (the context hash avoids pushing either way), whether `gpu-a40-small` is still offered (apply checks `GET /v1/hardware`), and what a prediction answers while no instance is up.
