## How to verify

```sh
cd python && uv sync --locked && uv run ruff check . && uv run pytest        # unit and golden
cd router && cargo fmt --all --check && cargo clippy --workspace --all-targets -- -D warnings && cargo test --workspace
cd testing/mock-server && uv sync --locked && uv run pytest -q
cd testing/live && uv sync --locked && uv run pytest -q tests/test_00_*.py  # live unit tests, no cluster
make e2e                                   # local failover matrix, Docker, about 4 minutes; E2E_RUN_ID=<id> isolates concurrent runs
make demo DEMO_ARGS="--duration 60 --scripted --check --no-top"   # scripted demo, asserts zero client errors and a failover
make kind-up && make e2e-kind && make kind-down                    # kind primary, docker secondary
make kind-in-cluster-up && make kind-in-cluster && make kind-in-cluster-down   # chart-installed controller and router
cd website && npm ci && npm run build                              # needs Node 24 and uv
helm lint charts/multihull && HULL="uv run --project $PWD/python hull" charts/multihull/tests/render.sh   # after make router-release
gh workflow run live-smoke.yml             # or label a PR live-smoke; kind plus Modal CPU, cents per run
gh workflow run live-gpu.yml -f max_minutes=20   # owner only; two Modal L4s, about 0.06 USD when cached, 5 USD cap
```

If `cargo` is missing, add `$HOME/.cargo/bin` or `$(brew --prefix rustup)/bin` to `PATH`. Live smoke passes when every scenario row is `pass`, the failover row shows zero client 5xx and traffic on Modal, and the Modal section says nothing was left. Live GPU passes when the summary shows every scenario `pass`, `Served by` `modal-a` then `modal-b`, zero client errors and `Cost` within budget (`docs/runbooks/live-gpu.md`, "What to check in the summary"). Releases: `docs/runbooks/release.md`.

## Lessons

**Modal**
- Env vars being set says nothing; a rejected token reached deploy until `hull doctor` made an authenticated call (run 37666477209, PR 37).
- `No module named pip` in an image build means the legacy 2023.12 builder ran; pin `2025.06` (run 37667963715, PR 37).
- One container with `max_inputs` 32 answers 408 above it; keep fallbacks above the 1.4 overprovision floor and treat 408 as Transient (run 37678680863, PR 37).
- `num_total_runners` counts containers before vLLM listens; only a 2xx on the health path is Ready. First deploy about 5 minutes, cached about 90 s (run 37804601404, PR 120).
- Modal execs its runtime through the image entrypoint; an image whose entrypoint parses arguments exits 2 until `ENTRYPOINT []` is set (run 37809376724, PR 120).
- A stopped app answers `404 invalid function call` for about 14 s until three probes fail, and 4xx is not retried, so those requests reach the client (PR 120, issue 122).

**Kubernetes and kind**
- Give kind its own `--kubeconfig` so a local run never changes the current context (PR 111).
- `kubectl create secret --from-literal` writes the value into `kubectl.log` through `run_logged`; use `--from-file` (PR 101).
- `hull` as PID 1 ignored SIGTERM, so every rollout waited 30 s; the in-cluster restart check (under 30 s) catches it (PR 101).
- A restarted controller that numbers snapshots from 1 is nacked by routers holding a higher version; versions come from state and router hellos (PR 101, fixed in PR 111).

**Router**
- A probe success must never close a circuit, and a streamed disconnect recorded after the first-byte success gives exactly 0.5 error ratio that strict `>` never trips: release into half-open, record streamed outcomes once at body end (PR 33).
- A short queue wait cleared queue pressure while others still waited, so `Degraded` went unsent under saturation (PR 35).
- Reaching `timeouts.total` must not blame the endpoint or be retried; reserve headroom before spending the half-open trial (PR 86).
- A health path without a leading slash built a probe URL with the wrong host and ejected every endpoint (PR 83).
- The router never retries a keyless POST; demo and test load send an `Idempotency-Key` per request (PR 130).
- `router_requests_total` counts upstream attempts and has no client-visible status; use `router_responses_total{route,status}` for route totals (PR 131).
- The local harness found eight router bugs unit tests missed; run `make e2e` before claiming failover works (PR 25).

**Control plane**
- `with sqlite3.connect() as conn` never closes the connection; leaked handles kept `-wal` and `-shm` alive across a `state.db` unlink and the rebuilt file read back empty (PR 111).
- Silence is not recovery: the router sent `Degraded` once per episode, so scale-back fired while pressure held; re-send until a healthy window. Raised floors kept only in memory vanish on restart (PRs 85, 96).
- Update `min_replicas` only after the scale call succeeds; a refusal is logged intent, not state (PR 30).
- A controller with no reachable targets writes no snapshot file; wait for the listening log line (PR 111).
- Open router streams held shutdown for the 5 s gRPC grace; close them before stopping the server. A warm Docker builder with a uv cache mount reused the cached wheel of the local project; build the project layer with `--no-cache` (PR 101).

**CI and GitHub**
- `pytest -x` hides later failures behind the first (PR 35); `timeout` does not exist on macOS, use a pytest timeout.
- `dorny/paths-filter` needs `pull-requests: read` (2026-10-01); job-level `permissions` sets unlisted scopes to none, so `publish-crates` needed `contents: read` to check out (PR 99).
- Path filters are not evaluated on tag pushes, so `images.yml` runs on every `v*` tag (PR 90).
- Workflow expressions have no arithmetic (GPU step timeout fixed at 35 minutes, `max_minutes` capped at 30); `collect_ignore_glob` keeps the GPU tests out of the kind suite where a skip marker would add summary rows (PR 114).
- Before PR 97 any e2e run's sweeper removed every `e2e-three` container; each run now sweeps only its `E2E_RUN_ID`.
- GitHub-hosted runners share Docker Hub's anonymous quota (100 pulls per 6 h per IPv4), so PR 138 failed with 429 in every image job; base images come from `public.ecr.aws/docker/library` and `kindest/node` from `mirror.gcr.io`, same digests, no login (issue 139). A kind older than the node image's release fails `kubeadm init` with "old API spec v1beta3": local kind must match `helm/kind-action` (v0.33.0). `docker/setup-buildx-action` pulls `moby/buildkit:buildx-stable-1` from Docker Hub for its builder container; `driver-opts: image=mirror.gcr.io/moby/buildkit:...` moves that too (run 37994861794).
- Packages inherit repository permissions, not visibility, and the account spending limit stops Actions on a private repo: the repo went public on 2026-10-08, the packages were switched separately.
- `GITLEAKS_LICENSE` is needed only for organization-owned repos; without `GITLEAKS_VERSION` the action downloads the latest release (PR 129).
- CodeQL taints by name: a helper called `secret_commands` became a source on its own, and alert paths started at env variable name constants (PR 132).
- Subagents may append `Claude-Session` trailers; check `git log --format=%B` before pushing. Subagent replies do not reach the owner; relay through the parent.

**PyPI and crates.io**
- PyPI checks pending publishers before project publishers; a stale pending entry answers `invalid-pending-publisher` for an existing project. Rerun only the failed job first (`gh run rerun <id> --failed`, run 37895991523).
- `cargo publish --dry-run` on an already published version only warns, so PR CI stays green after a release; `router-testkit` builds its own rustls config so it stays a versionless path dev-dependency that `cargo publish` strips (PR 100).

**Docs site**
- Cloudflare never expires preview deployments; `docs-preview-sweep.yml` deletes them after 24 h (2026-10-02).
- A version snapshot taken after the tag misses docs merged in between (0.1.0 predates PRs 125, 126); snapshot in the tagging PR. `current.redirect: 'root'` would send every version switch to the landing page (PR 128).
- In `generate-reference.mjs`, a code fence must be longer than any backtick run in the value, and `|` is the only escape in a table cell since backslashes are literal in code spans (PR 132).
