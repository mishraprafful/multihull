# Contributing to Multihull

Thanks for helping. Multihull deploys always-warm GPU inference containers to many providers from one `multihull.yaml`, serves them behind one URL and fails over between providers per request. A Python control plane translates the spec into each provider's native resources; a stateless Rust router scores endpoints and retries across providers.

One principle decides what gets merged: **reliability over cost**. Defaults keep at least two providers warm, never scale fallbacks to zero and prefer on-demand over spot. Cost features are welcome as opt-in and may never lower the configured redundancy floor. In the router, health beats price.

Coding agents: read [AGENTS.md](AGENTS.md) instead; it covers the same rules in agent form.

## Ways to contribute

- Bug reports: open a GitHub issue with the spec, the command, the output and the provider involved. Strip credentials first.
- Security vulnerabilities: never in a public issue. Report them privately as described in [SECURITY.md](SECURITY.md).
- Provider translators: one translator per provider, written against that provider's native SDK or API. No CRDs, no operators, no shim processes.
- Router policies: scoring, circuits, retry budgets, sticky routing. Keep `router-core` free of IO.
- Docs: the Astro Starlight site under `website/` and the design docs under `docs/design/`.

Read [docs/design/architecture-plan.md](docs/design/architecture-plan.md) before changing `python/`, `router/` or `proto/`. [docs/handover.md](docs/handover.md) holds current state and next steps.

## Development setup

Clone the repo and work in the area you are changing. CI runs the same commands, path-filtered per area (`.github/workflows/ci.yml`).

### Python (`python/`)

Requires Python 3.11+ and [uv](https://docs.astral.sh/uv/).

```sh
cd python
uv sync --locked
uv run ruff check .
uv run ruff format --check .
uv run pytest
```

### Control-plane image (`python/Dockerfile`)

```sh
docker build -t multihull-controller:dev python
docker run --rm multihull-controller:dev --help
```

`images.yml` publishes it as `ghcr.io/mishraprafful/multihull-controller`; the chart's controller runs it.

### Rust (`router/`)

Requires rustup stable with `rustfmt` and `clippy`. If `cargo` is not on `PATH`:

```sh
export PATH="$HOME/.cargo/bin:$(brew --prefix rustup)/bin:$PATH"
```

```sh
cd router
cargo fmt --all --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
```

Proto code is generated by `tonic-prost-build` with a vendored `protoc`; no system `protoc` needed.

### Website (`website/`)

Requires Node 24 and `uv` on `PATH` (the build generates reference pages from the Python package).

```sh
cd website
npm ci
npm run build
```

`npm run dev` serves at http://localhost:4321. Edit sources, not the generated pages listed in [website/README.md](website/README.md).

### Chart (`charts/multihull/`)

```sh
helm lint charts/multihull
helm template multihull charts/multihull > /dev/null
(cd router && cargo build --release -p multihull)
HULL="uv run --project $PWD/python hull" charts/multihull/tests/render.sh
```

`render.sh` renders `router.toml` with the value files in `charts/multihull/tests/values/` and the TLS, token and plaintext opt-in cases, and loads each with `multihull --check-config`. It also checks the controller Deployment's command against `hull controller --help`, its state volume and `envFrom`, and that refused values fail the render. Helm may be absent locally; CI installs it and runs these for you.

To run the chart's controller and router in kind with images built from your tree (needs `helm` on `PATH` or in `HELM`):

```sh
kind create cluster --name multihull-in-cluster
make kind-in-cluster
kind delete cluster --name multihull-in-cluster
```

## Running tests

The commands above run layer 1 (unit and golden) and layer 2 (contract) tests. Every translator has a golden test: spec in, native payload out, compared against `python/tests/golden/`. The end-to-end layers, from local Docker fakes to live GPU smoke, are defined in [docs/design/testing-strategy.md](docs/design/testing-strategy.md).

## Pull requests

1. Branch from `main`.
2. Commit with [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/): `type(scope): subject`, imperative mood, no trailing period. Types: `feat`, `fix`, `chore`, `refactor`, `docs`, `test`, `perf`, `build`, `ci`, `style`, `revert`.
3. Atomic commits, one logical change each. Stage selectively.
4. Open the PR as a draft and fill in `.github/pull_request_template.md`. The PR title follows the same commit format; the repo squash-merges with it.
5. Keep the description under 100 words: what changed and why.
6. No AI attribution trailers or footers in commits or descriptions.
7. Never force push. Add a new commit to change something already pushed.
8. CI must be green before review.

PRs touching `website/`, `docs/` or `python/` get a Cloudflare Pages preview deployment and one sticky comment with the URL. Previews are swept after 24 hours; push again for a fresh link.

## Adding a provider

1. Implement the `Provider` Protocol from `python/multihull/providers/base.py` in a new module under `python/multihull/providers/`, using the provider's own SDK or REST API.
2. Add the type to `ProviderType` in `python/multihull/spec.py` and register the class in `PROVIDERS` in `python/multihull/providers/registry.py`.
3. Add a golden test rendering `examples/llama-8b/multihull.yaml` and commit the expected payload under `python/tests/golden/`.
4. Add a column to the translation table in `docs/design/architecture-plan.md`.
5. Add a docs page under `website/src/content/docs/docs/providers/`.

Tag every created resource with `multihull.dev/service=<name>` so `rediscover` can rebuild state. Credentials are read from environment variables; `hull doctor` reports them via `credentials_health`.

## Code style

- Self-documenting code: clear names and structure, no explanatory comments or docstrings.
- Type hints everywhere in Python; pydantic v2, typer, httpx.
- No secrets in code, config, docs, tests or commit messages. Reference them by env var name or file location.
- Rust 2021 edition, tokio, hyper 1.x, tower, rustls, tonic. Clippy clean with `-D warnings`.
- No em dashes in prose. Use a comma, colon, parentheses or a new sentence.
